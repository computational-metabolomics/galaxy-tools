# README images

Logos used in the main README's acknowledgements, copied from the sources below. The BioFAIR,
ELIXIR and Galaxy logos have transparent backgrounds and dark text, so a white background and a
little padding were added to keep them legible in GitHub's dark theme; the other logos are
unchanged. Display sizes are set in the README.

| File | Source |
| --- | --- |
| `biofair-logo.png` | [BioFAIR website logo](https://biofair.uk/wp-content/uploads/2023/04/BioFAIR-logo.png), used on the [BioFAIR homepage](https://biofair.uk/). |
| `elixir-logo.svg` | [ELIXIR Europe logo](https://elixir-belgium.github.io/elixir-toolkit-theme/images/infrastructures/ELIXIR-logo.svg), distributed by the [ELIXIR Toolkit Theme](https://elixir-belgium.github.io/elixir-toolkit-theme/supported_by). |
| `european-union-emblem.jpg` | `normal-reproduction-high-resolution.jpg` from the [official European flag download](https://european-union.europa.eu/document/download/08833e82-bd69-4333-ab35-ef530c45739c_en?filename=normal-reproduction-high-resolution.zip), linked from the [European Union website](https://european-union.europa.eu/principles-countries-history/symbols/european-flag_en). |
| `galaxy-logo.svg` | [Galaxy Community Hub logo](https://galaxyproject.org/images/galaxy_logo_hub.svg), from the [Galaxy Community Hub](https://galaxyproject.org/). |
| `workflow4metabolomics-logo.jpg` | [W4M long logo](https://workflow4metabolomics.github.io/website/images/logo/W4M_long_logo.jpg) from the [Workflow4Metabolomics website](https://workflow4metabolomics.github.io/website/). |

The logos remain the property of their owners and are shown to acknowledge support. ELIXIR
logo presentation guidance is in the [ELIXIR Brand Guidelines](https://elixir-europe.org/sites/default/files/documents/elixir-brand-guidelines-2025.pdf).
Funders may also set rules for how their emblem is used in an acknowledgement, so check the
terms of the relevant funding before changing how these logos appear.
